How to read this

A clue, not a verdict.

Relative change matters more than raw popularity. Stable high-volume conversation is suppressed when it matches its longer baseline.

Cheap first pass tracks decaying unigram and bigram rates. Only posts with enough surprising recent language become candidates.

Semantic confirmation groups differently worded candidate posts with a small local sentence-embedding model running off the UI thread.

Evidence controls require volume and source diversity, suppress exact repeats and source floods, and expose each score component for inspection.

Live posts come from the public Bluesky Jetstream. Candidate embeddings use all-MiniLM-L6-v2 through Transformers.js.

Language labels are author-supplied, semantic similarity is approximate, and all counters are bounded, decaying estimates rather than an archive.
